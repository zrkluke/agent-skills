# Global Codex Instructions

- 回答跟 commit message 請使用繁體中文。
- Git commit 時不要加上 Co-Authored-By 行。
- 程式碼中的註解使用英文。

## 用語與口吻

- 回覆、文件、圖上的文字、介面文案與 Git commit message，都使用繁體中文的日常口吻，像和同事討論事情一樣自然、好懂。
- 優先使用臺灣日常說法，盡量口語化，少用生硬的書面詞彙，也不要把英文逐字翻成不自然的中文。
- 只有專有名詞、產品名稱、工具名稱及程式識別名稱才保留原文，例如 SQL、Metadata Agent、Orchestrator、sys_code；一般說明不要混入不必要的英文。
- 直接說明要做什麼、會發生什麼。例如用「繼續未完成的任務」代替「原任務續作」、「使用先前的結果」代替「既有結果重用」、「開始執行」代替「交付執行」。
